# T-CD 简表填写

界面顶部有独立的“日报模板”和“简表模板”上传区，可分别拖放、粘贴或上传 `.xlsx` 文件，并单独清除。日报上传含“调价前”的旧模板；简表支持 T-CD、T-XW 等首张工作表为数据简表的模板，按工作表顺序定位，不要求名称为 Sheet1。

下表的 Sheet1 指第一张工作表。第二张工作表仅在 A4 为“油品”、A10 为“充值明细”时填写标准明细；缺少第二张表或其布局不同，仍可生成简表，其他页保留原值。

可以只选择其中一个，也可以同时选择两个。原生桌面版点击“计算并保存”后，程序共用源数据，完成计算、识别和工作簿校验，再分别备份并保存回所选模板，不需要导出。每次写入前的原件保存在同目录“报表备份”文件夹，备份文件名含时间和唯一后缀。原文件被占用、只读或处理期间被外部修改时，保存失败并保持原文件内容。模板不能与源数据或其他站点的模板共用同一文件；同名但不同路径的模板仍可分别处理。计算、识别或校验失败时不写回对应模板，另一份报表仍可独立完成。

处理或保存尚未完成时不允许更换模板或重置。预览使用已保存结果的固定副本；修改参数后须重新计算。重置或移除站点只清理选择和临时结果，不删除已保存报表或备份。Python 对照版保留原有副本和导出流程。

简表必需源表为油品时间统计、加油明细、充值明细。油品优惠表可选：上传后核对优惠并填写相应栏位；未上传则保留优惠栏原值。只要上传了日报模板，就仍需日报原有的四份源表。国通1、国通2等图片均可选。

时间统计分为两份时，在“其他表格”中上传“油品时间统计(调价后)”。程序会合并原始升数、金额和次数，与完整时段的加油明细核对；两段导出时段合起来应与加油明细、充值明细一致。同油品单价未变时，按机号合并两份原始升数后再折算。实际调价时，按统计时段和明细中的“加油完成时间”确认各段单价；同一统计时段混有多个单价时停止计算，要求按调价时间拆分统计。

日报和简表使用独立更新批次和保存状态；某一报表校验或保存失败，不影响另一份独立报表完成。失败后可修正源数据或保存问题并重新处理。

图片识别遇到网络错误、HTTP 429 或 5xx 时最多请求 3 次，重试前分别等待 5 秒、10 秒；其他 HTTP 错误和缺失识别字段立即报错。国通1/国通2支持两种截图：订单汇总表使用订单金额减退款订单金额；交易明细表直接使用金额列末行合计。汇总表缺少退款金额仍会报错，不默认为零。

金额、升数、次数默认除以 3。以下规则采用用户确认的 20 日已校验样本特征；不是所有字段都使用同一种金额列或舍入顺序。

## 已确认的填写规则

| 位置 | 规则 |
| --- | --- |
| Sheet1 A3:A5 | 依次为 0#柴油、92#汽油、95#汽油 |
| B3:B5 | 同一油品未调价时，同机号原始升数先合并，再折算取两位并汇总；实际调价时分别计算各段折算升数后相加 |
| D3:D5 | 始终按折算升数乘加油明细单价计算。实际调价时，各段折算升数乘各段单价后相加，最后取两位；不使用原始“加油元÷3”代替 |
| E3:E5 | 每种油品调价前后的原次数先相加，再除以次数除数、四舍五入到整数，不分别取整后相加 |
| C3:C5、F3:F6 | 升数占比、平均金额通过公式计算，不再额外除以 3；零分母返回 0 |
| B8 新次数 | 原余额为 0，付款方式为现金/微信/支付宝的充值明细条数，折算取两位；无记录留空 |
| B9 旧次数 | 按已校验样本，取充值表全部明细条数，含开户、撤单，折算取两位。此处不按原余额非零筛选，也不减去新次数 |
| D8 新充值 | 原余额为 0，现金/微信/支付宝记录的充值金额加充值赠送，折算取两位；无记录留空 |
| D9 旧充值 | 原余额非 0，现金/微信/支付宝记录的充值金额加充值赠送，折算取两位；保留负金额，付款方式为空的撤单不计金额 |
| B11 超市 | 使用与日报“调价前!H71”相同的超市销售收入：每张超市截图的现金金额除以 3、取两位后累加。双模板直接复用本次日报结果，不重复识别或折算；只填简表时也可上传超市截图。没有截图则保留 B11 原值 |
| D11 充值消费 | 充值卡收款、电子卡收款各自的结算金额合计，分别折算取两位后相加 |
| B12 线上充值 | 微信/支付宝记录的充值金额合计，折算取两位，不加赠送 |
| D12 线上消费 | 电子卡收款的结算金额合计，折算取两位；已包含于 D11，不能再相加作总消费 |
| B13 无卡次数 | 同时满足优惠金额为 0、IC卡余额为 0、结算金额非 0、油品为 92 或 95，排除回罐收款后的明细条数，折算取整数；不额外按卡号筛选。IC卡余额缺失或无效时报错，不默认为零 |
| D13 无卡金额 | 与 B13 相同筛选条件，汇总结算金额，折算取两位 |
| F11:F13 | 消费占比、线上消费占比、无卡金额占比联动计算 |
| G7 | 按用户指定地址，填写输入的截图期末余额合计除以金额除数，取两位；输入空白则不覆盖，输入 0 则写入 0 |
| Sheet2 D5:D7 | 平均消费升数公式，零分母返回 0 |
| Sheet2 D31、D34 | 有油品优惠表时，分别填写汽油、柴油优惠合计折算金额，包含优惠券造成的减额 |

日期来自界面设置。全部舍入使用十进制四舍五入，避免浮点数和银行家舍入造成的一分钱差异。
用户后续确认加油消费统一使用结算金额，因此 D11、D12、D13 均取结算列，不依赖实收金额列。D8/D9 属于充值，仍使用充值金额加赠送，不受消费金额口径调整影响。D8 的赠送按 D9 相同规则处理，已校验样本未包含新充值。

## 保留项与余额输入

未写说明的空格不计算、不覆盖，包括新会 B10、积分 D10、洗车、充值面额明细、汽柴油充值分类、平台优惠等。超市 B11 仅在提供超市销售收入截图时填写。已有公式和数值保留，不能当作本次自动计算的结果。

余额截图不自动识别。将截图中期末余额合计输入简表选项，程序按约定写入 G7，不拆分实体卡、线上卡或新旧系统。
G7 在原模板中是“卡余额”标题，这是用户明确指定的写入地址；G8/H8/I8/J8 及其现有合计公式不改动。

## 校验与支持范围

- 写入前核对源表导出时段、可用数字站号，以及各油品原始升数、油机金额、次数；不拿折算后的显示金额反查原始金额。
- 有优惠表时，对照油机金额减结算金额校验，不能仅用优惠金额列，因为优惠券也会减少结算金额。
- 排除合计、小计等汇总行，清理收款方式等字段前后空格；开户、撤单仍是充值明细，参与 B9 的计数。
- 缺少必需字段、数字无效、油品未知、站号或合并时段、汇总不一致时停止写入。某油品存在多个单价时，必须提供调价后统计、各段完整时段和有效的加油完成时间，核对各段升数后按对应单价计算。
- 原生日报与简表共用油量分组规则。未调价的油品合并填入“调价前”，真正调价的油品分别填入前后页；清零参与更新页的旧油量，并使用原始明细单价填写对应油枪单价，保留金额公式，防止模板旧价格参与本次计算。
- 保留负充值金额，不再将其一律判作错误。不自动生成未说明的充值面额明细。

## 旧表

旧表仍要求原有四份源表。国通1、国通2与其他图片均为可选，不上传也可处理；上传后仍按原有图片流程处理。此前已修复的收款方式空格、优惠分组小计排除及输出副本路径问题继续保留。本次简表的金额、舍入与次数规则不改动旧表算法。
